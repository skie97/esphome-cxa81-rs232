## [0.1.0] - 2026-01-26

### Added
- Initial release of CXA81 RS232 ESPHome external component
- Power control (on/off)
- Mute control
- Source selection
- Source next/previous buttons
- Protocol version, firmware version, and error reporting
- ESP-IDF framework support

### Notes
- Verified with MAX3232 DB9 RS232 module
- See wiring note regarding RXD/TXD labeling differences
